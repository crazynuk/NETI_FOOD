NETI Food — цифровая столовая НГТУ НЭТИ: предзаказ еды на перемену и выдача через умный постамат. FastAPI + PWA + Android-приложение.
iPhone / iPad
Отдельная установка не нужна — NETI Food работает как PWA-приложение.
1. Подключите iPhone к Wi-Fi
2. Откройте в **Safari** адрес сервера, напишите `https://sly-sandbag-outshoot.ngrok-free.dev`. При первом подключении откроется страница ngrok с предупреждением — нажмите **«Visit Site»**.
3. ## 📱 Запуск приложения на Android
1. Откройте приложение **NETI Food**.
2. Появится окно **«Адрес сервера NETI Food»** со стандартным адресом `http://192.168.0.100:8000`.
3. Сотрите его и вставьте адрес нашего сервера:

   **`https://sly-sandbag-outshoot.ngrok-free.dev`**

4. Нажмите **«Подключиться»**.
5. При первом подключении откроется страница ngrok с предупреждением — нажмите **«Visit Site»**. Больше она не появится.

Готово! Приложение запомнит адрес, и в следующий раз откроется сразу.
